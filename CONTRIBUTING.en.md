# How to contribute

Thanks for wanting to help. This guide sums up what a change should meet. If you work with an AI assistant, give it [AGENTS.md](AGENTS.md) too.

## Before you start

1. Read the [README](README.en.md) and the [build guide](docs/en/GUIDE.md). `pwsh scripts/doctor.ps1` tells you what your machine is missing.
2. For big changes, open an issue first and say what you want to do, to avoid duplicated work.
3. Always use the pinned toolchain, `nightly-2026-09-29`.

## What a change must meet

- **No game or game data** in the repository, issues, logs or screenshots. Automated tests use synthetic or free data.
- **No paths or details of your machine** (home folder, user name, emails, tokens). Use relative paths or parameters.
- **Tests:** new code comes with its test. Logic that does not depend on the console (formats, parsers, file copies, button mapping) is tested on the PC.
- **A single NRO** as the deliverable. `pokenx/` is generated by `app/build-package.ps1` and is not versioned.
- **NRO start-up:** never link with `-z notext` without the relocation check (`scripts/verify_relocations.py)` and do not silence `read-only segment has dynamic relocations`. Details in [SYSTEM.md](docs/en/SYSTEM.md#safe-start-of-the-nro).
- **Graphical menu:** no `consoleInit`/`printf` while it is active; every new screen is checked with the preview (`tools/menu_preview`).
- **Clear code:** the simplest solution that meets the behaviour. Match the style of the code you touch.

## Before sending

```powershell
pwsh scripts/check.ps1        # PC tests and cross-compilation of the engine
pwsh app/build-package.ps1    # if you touched the NRO: note the size and SHA-256
```

Continuous integration runs `scripts/check.ps1` on every push. **Building is not "it works":** in your description say how far you got (builds on the PC, builds for the Switch, NRO generated, opens, renders, sounds, controls, playable) and which you did not test. Console tests are done by whoever has one; nobody has to own a console to contribute.

## Issues

Use the template. The logs (`boot.log`, `engine.log`, `crash.log`, `informe.txt`) contain no game data and help the most.

## Commit messages

A clear first line in the imperative (what changes) and, if needed, a paragraph with the why. No local paths or machine names.
